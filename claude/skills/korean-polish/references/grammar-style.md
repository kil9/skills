# 맞춤법·띄어쓰기·문장부호·일관성

규범 정본은 국립국어원 한글 맞춤법·표준어 규정·외래어 표기법·문장 부호 규정이다. 헷갈리면
표준국어대사전으로 한 번 더 확인한다. 고칠 때 확신도를 붙인다.

- **오류**: 규범 위반. 고친다.
- **권장**: 규범은 허용하지만 더 낫다. 고치고 이유 한 줄.
- **제안**: 취향·문맥. 보고만 한다.

## 1. 자주 틀리는 맞춤법(오류)

| 규칙 | 틀림 → 맞음 |
|---|---|
| 되/돼: '하/해' 를 넣어 본다 | 되요 → 돼요, 됬다 → 됐다, 안되요 → 안 돼요 |
| 안(부사)/않(-지 않다) | 하지 안다 → 하지 않다, 않 가요 → 안 가요 |
| -ㄹ게, -ㄹ걸 (된소리로 적지 않음, 어미라 붙임) | 할께요 → 할게요, 갈껄 → 갈걸 |
| 형용사 -ㄴ지 / 동사 -는지 | 좋는지 → 좋은지 |
| 던(회상)/든(선택) | 뭐던 좋아요 → 뭐든 좋아요 |
| 로서(자격)/로써(수단) | 담당자로써 → 담당자로서, 이것으로서 해결 → 이것으로써 해결 |
| 웬(어찌 된)/왠지 | 왠 일 → 웬일 |
| 어떻게/어떡해(= 어떻게 해) | 어떻해 → 어떡해 |
| -습니다(받침 뒤) | 있읍니다 → 있습니다 |
| 사이시옷(고유어 결합 + 곳간·셋방·숫자·찻간·툇간·횟수) | 회수(횟수 뜻) → 횟수, 나무잎 → 나뭇잎 |
| 이중 피동 '-되어지다' (비문) | 생성되어진다 → 생성된다 |
| 외래어 표기 | 메세지 → 메시지, 쉐어 → 셰어, 컨텐츠 → 콘텐츠, 어플 → 앱 |

## 2. 띄어쓰기

- 의존명사는 띄운다: 할 수, 하는 것, 먹을 만큼, 갈 뿐, 할 줄, 한 지 3일, 하는 데(경우·장소).
  - 같은 꼴의 어미는 붙인다: 하는데(연결), 가는지(의문), 체언 뒤 조사 '만큼'·'뿐'(너만큼, 너뿐).
- '-지 않다' 의 '않다' 는 띄운다. 부정 부사 '안' 도 띄운다(안 돼요).
- 보조용언(-아 주다, -고 있다, -아 보다)은 띄우는 것이 원칙, 붙임도 허용. **한 글 안에서 하나로.**
- 합성어는 붙인다(읽을거리, 손목시계). 사전에 한 단어로 있는지 본다.
- 숫자 + 단위 의존명사: 아라비아 숫자 뒤는 붙인다(3개, 5명, 10,000원, 3시간). 한글 수사 뒤는
  띄운다(세 개). SI 기호(kg, km, °C)는 한 글 안에서 하나로(국제 표기는 띄움). `%` 는 붙인다.
- **일부러 틀리게 띄우지 않는다.** AI 탐지를 피하려고 의존명사를 붙이라는 처방이 있지만 맞춤법
  오류다. 이 스킬은 쓰지 않는다.

## 3. 문장부호

- 쉼표: 연결어미(-고, -어서, -지만, -면서, -며, -는데) 뒤, 주어 뒤, 짧은 목록의 쉼표를 뺀다.
  쉼표로 독립절을 잇지 말고 마침표로 나눈다.
- 콜론: "다음과 같습니다:", "방법:" 같은 도입 콜론은 마침표나 문장으로. 시각(3:30)·비율(2:1)·
  키-값 표기는 그대로.
- 줄표(—): 단락당 1회 이하. 괄호나 문장 분리로 바꾼다. 사용자·프로젝트 규칙이 금지하면 0회.
- 가운뎃점(·): 짝이나 공통 성분을 줄일 때만(읽기·쓰기 권한, 한·미). 독립된 항목 나열은 쉼표나
  `/`(쿠키, 세션, JWT).
- 범위: 물결표(\~)와 붙임표(-) 모두 규범이 허용한다. 한 글 안에서 하나로. 마크다운에서 `~` 를
  쓰면 `\~` 로 escape 한다(GFM 이 `~text~` 를 취소선으로 렌더링).
- 느낌표는 하나, 업무 글에서는 거의 쓰지 않는다. 따옴표는 짝을 맞춘다.

## 4. 일관성(한 글 안에서 하나로)

판단 순서: 사용자·프로젝트가 정한 규칙(용어집, CLAUDE.md, 스타일 스킬) → 규범·업계 표준 → 글 안의
다수결(빈도를 세서 많이 쓴 쪽). 의도적 대비, 인용, 고유명사, 코드는 건드리지 않는다. 뜻이 실제로
다르면 혼용을 허용한다.

- **어조**: 종결어미 체계 하나(-습니다 / -한다 / -해요). 최소 한 단락 안에서는 반드시 통일한다.
  주어 호칭도 하나(대외 '저희', 내부 '우리', 기술 문서는 1인칭 회피).
- **용어**: 같은 개념은 한 낱말로(사용자/유저/이용자, 저장/세이브, 설정/세팅). 한자어와 고유어를
  섞지 않는다(변경/바꿈). 약어는 첫 등장에 풀어 쓰거나 끝까지 한쪽으로(데이터베이스/DB).
- **숫자**: 통계·날짜·금액·측정값은 아라비아 숫자, 관용 표현은 한글(한두 번). 천 단위 쉼표.
  10,000원과 1만 원을 섞지 않는다.
- **목록**: 같은 수준은 같은 부호, 한 목록 안의 종결 하나(완전 문장 / 명사형 / -하기).
  제목은 명사형으로 짧게("설치 방법").
- **날짜·시간**: 기술 문서·로그는 ISO `YYYY-MM-DD` + 24시간제, 업무 문서는 `YYYY년 M월 D일`.
  오전/오후와 24시간제, 한글과 AM/PM 을 섞지 않는다. 슬래시 날짜(01/27/2026)는 피한다.
- **강조**: 굵게는 핵심 한두 곳. 코드·명령·경로는 백틱. 밑줄은 링크로 오해된다.

## 5. 장르 기본값

| | 어조 | 용어 | 숫자·날짜 | 목록 |
|---|---|---|---|---|
| 화면 문구 | 제품이 정한 체 하나(합니다/해요) | 쉬운 말, 기능 이름과 일치 | 아라비아 + 단위 붙임, 화면은 `10/12(월)` 류 | 버튼·메뉴 명사형 |
| 기술 문서·README | -한다 / -합니다(문서 단위로 하나) | 업계 약어 허용 | ISO 날짜 | 명사형 또는 -한다 |
| 커밋·PR·이슈 | 저장소 관례(최근 커밋을 본다) | 식별자는 백틱 | ISO | 자유, 목록 안 일관 |
| 업무 글·메일 | -습니다 | 표준 용어 | `YYYY년 M월 D일` | 완전 문장 |
| 블로그 | -해요 / -다 | 친숙한 말 | 자유 | 자유 |
