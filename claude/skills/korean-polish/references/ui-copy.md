# 화면 문구(UI 마이크로카피)

대시보드·운영 도구·앱 화면의 짧은 글: 결론 문장, 라벨, 표 머리, 배지, 빈 상태, 버튼. 문장이 짧아
AI투 카탈로그보다 **낱말 선택**과 **한 화면 안의 일관성**이 거의 전부다. 사례는 실제로 사용자에게
"어색하다" 는 평을 받고 고친 것이다(2026-10 지표 모니터 화면). 사례는 판단의 예이지 정답표가
아니다. 다른 화면에서는 그 화면의 기능 이름과 값으로 다시 판단한다.

## 1. 결론 문장: 무엇이 어떤가를 그대로 말한다

- 추상명사·사건에 이동·행위 동사를 붙이지 않는다. "이탈이 메일로 나간다" 는 번역투 의인화다.
  - 메일로 나갈 이탈은 없습니다 → **메일 발송 대상은 없습니다**
  - 경보 이상 3건이 진행 중입니다 → 메일 발송 대상 3건이 진행 중입니다
- 상태 문장은 상태 명사로 닫는다. 진행 중인 이탈이 없습니다 → **이상 상태가 없습니다**
- 한 결론 블록 안의 여러 상황(문제 없음 / 주의만 / 경보 이상)은 같은 틀의 문장 세트로 만든다.
  하나만 고치고 나머지를 옛 틀로 두지 않는다.

## 2. 도메인 용어: 쉬운 말, 기능 이름과 같은 말

- 업계·팀 안에서만 도는 한자어(이탈, 결손, 해소 …)가 화면 전면에 오면 먼저 의심한다.
  "기술 용어라 보존" 은 문서 본문 규칙이고, 화면 문구는 처음 보는 사람이 읽는다.
- 대안이 여럿이면 **기능 이름과 같은 말**을 먼저 본다. 이상 감지 기능의 '이탈' → '이상'.
  메일·화면·기능명이 한 낱말로 묶인다.
- 용어 교체는 사용자 몫이다. 2-4개 안을 `AskUserQuestion` 으로, 미리보기에 대표 문장 6-8개를
  `전 → 후` 로 보여 주고 고르게 한다. 사용자가 메모로 준 문장은 그대로 쓴다.
- 고른 뒤에는 **보이는 문자열을 전부** 한 번에 바꾼다: 화면, 상세 화면, 차트 범례·툴팁, 메일
  템플릿, 빈 상태. 주석·테스트 이름·로그는 독자가 달라 그대로 둬도 된다(바꿀지 한 줄로 밝힌다).

## 3. 새 용어가 기존 표현과 겹치는지 본다

새 낱말이 화면에 이미 다른 뜻으로 있으면 둘 다 흐려진다. 교체 전에 grep 한다.

- '이상'(anomaly)을 들이자 '경보 이상'·'주의 이상'(= 그 등급부터)과 겹쳤다.
  - 경보 이상이면 메일 → **경보부터 메일**
  - 첫 이탈(주의 이상) → **처음 주의 등급에 닿은 날**
  - 이 띠 밖이 주의 이상 → 이 띠를 벗어나면 이상

## 4. 라벨·표 머리·배지

- 표 머리와 타일 라벨은 2-5자 명사구. 값의 단위와 호응시킨다. 값이 일수인지 날짜인지 먼저 본다.
  - 이탈일 → **이상 일수**(값 "1일"), 값이 날짜였다면 "이상이 시작된 날" 류
  - 최대 이탈 → **최대 폭**(값 "-13.6%")
- 부사 하나를 배지로 쓰지 않는다. '새로' 는 문장 성분이지 라벨이 아니다.
  - 새로 → **NEW**. 업계에서 굳은 짧은 영어 라벨(NEW, beta)은 어색한 직역보다 낫다.
    명사구("오늘 열림")도 된다.
- 라벨 + 숫자 묶음은 한 패턴으로: "오늘 새로 열림 6 · 오늘 이상이 확인된 규칙 10 / 212".
  "주의 15 건 진행 중" 처럼 숫자 뒤에 서술을 다시 붙이지 않는다.
- 압축 라벨 안의 '대비'("전주 대비", "중앙값 대비")는 관용이라 둔다. 문장 안에서는
  "기준선 대비 크게" → "기준선에서 크게" 처럼 조사로 푼다.

## 5. 어조

- 사용자에게 말하는 문장(결론, 빈 상태, 오류, 확인)은 제품이 정한 체 하나로 고정한다
  (합니다체 또는 해요체). 한 화면에서 섞지 않는다.
- 정의·도움말·범례 설명은 한다체 개조식을 허용한다. 단 한 블록 안에서 섞지 않는다.
- 빈 상태는 "무엇이 없다" 와, 알면 "언제 채워지는가" 를 함께: "아직 판정 이력이 없습니다. 스냅샷
  빌드가 탐지 회차를 돌면 채워집니다." 채워지는 조건을 모르면 지어내지 말고 원문대로 둔다.

## 6. 버튼·링크

- 버튼은 하는 일을 이름으로: 되돌리기, 저장, 펼치기. "확인" 은 정말 확인일 때만.
- 링크 글은 대상을 말한다. "여기", "클릭" 금지.
- 펼치기 요약 줄은 무엇이 몇 개 있는지: "해소된 에피소드 181개", "나머지 42개(정상·판정 없음)".

## 7. 작업 순서

1. 보이는 문자열 목록을 뽑는다(주석 제외 grep, 렌더된 페이지 텍스트).
2. 어색한 표현 → 대안 매핑표. 용어 교체면 사용자에게 고르게 한다.
3. 일괄 교체 후 겹침 grep(§3), 렌더된 화면 텍스트에서 옛 낱말이 0건인지 확인한다.
4. 길이가 바뀐 라벨은 좁은 화면에서 줄바꿈·잘림을 본다.
