# AI투·번역투 패턴 카탈로그

세 출처(sources.md)의 125개 패턴을 겹치는 것끼리 합친 것이다. 한 줄 형식:
`ID 이름 [심각도] 표지 → 처방 | 전 → 후`. 예외는 처방 뒤 괄호.

심각도:
- **S1**: 한 번만 나와도 고친다.
- **S2**: 한 단락에 3회 이상(표시한 것은 2회)일 때만 고친다. 1-2회는 둔다.
- **S3**: 단독으로는 약하다. 다른 패턴과 겹쳐 무더기일 때만 본다.

`*` 표시는 사람 글과 AI 글을 대조한 실측에서 판별력이 높게 나온 신호다. 진단은 이것부터 본다.

## C. 챗봇 잔재

- C1 머리말 [S1] "물론입니다!", "좋은 질문입니다", "다음은 \~입니다:" → 삭제
- C2 꼬리말 [S1] "도움이 되셨길", "추가 질문이 있으시면" → 삭제
- C3 지식 한계 면피 [S1] "제 지식은 \~까지", "공개된 정보가 제한적이지만" → "자료에 없다" 로 쓰거나 삭제. 추측을 사실로 포장하지 않는다

## V. 어휘·관용구

- V1 AI 유행어 [S1] 중요하다·핵심적·효과적·다양한·필수적·지속가능한 → 구체어로 바꾸거나 삭제 | 지속가능한 발전에 핵심적인 역할 → 장기 발전에 도움
- V2 hype 군집 [S2] 혁신적·획기적·압도적·전례 없는·다채로운·중추적·자리매김하다·방증하다·선사하다·\~의 향연 → 수치·사실로, 단락당 1개 (수치를 동반한 사실 진술은 둔다) | 압도적 성장 → 전년보다 47% 성장
- V3 의의 과장 [S1] 시사하는 바가 크다·주목할 만하다·이정표·새 지평·한 획을 그었다·\~의 산물 → 삭제하거나 구체 결론으로
- V4 결산 표지 [S1] 결론적으로·요약하면·정리하면·이를 통해 → 글 전체에 1개 이하, 짧은 글은 0개. 마지막 문단은 라벨 없이도 결론이다 (`## 결론` 헤딩은 둔다)
- V5 결말 공식 [S1] \~할 때입니다·지금이야말로·\~할 시점이다·귀추가 주목된다·무한한 가능성 → 구체 동사 단언, 문서당 1회 이하 | 지금이야말로 투자해야 할 때입니다 → 이제 더 투자해야 합니다
- V6 분열문 [S2] 핵심은/중요한 것은/관건은/문제는 X다 → 주어와 서술을 바로 잇는다
- V7 도치 결산 [S2] "\~하는 이유다" → "그래서 \~다". 고치면서 새로 만들지 않는다
- V8 범위·변환 공식 [S2·2회] "X에서 Y로", "단순한 X를 넘어 Y", "X가 아니라 Y" → 직접 단언, 문서당 1회
- V9 "더 이상 \~ 않다" 반복 [S2·2회] → "이제", 변화 동사로
- V10 기반 마련 공식 [S2] 발판·토대를 마련하다, 지평을 열다 → 실제로 무엇이 가능해지는지 쓴다. 내용이 없으면 은유만 평서로(여건이 갖춰진다)
- V11 문패 문장 [S2] "과제도 남아 있다", "한계도 분명하다" → 문패를 지우고 실제 과제를 첫 문장으로
- V12 생성형 은유 [S2] 잠식·청사진·적신호·신호탄·뿌리내리다, "진단은 서늘하다" → 명제로 | 시장을 잠식한다 → 점유율을 뺏는다. 같은 은유 반복은 1회만
- V13 불필요한 한자어 [S2] 진행하다·실시하다·수행하다·변경하다 → 하다·바꾸다 | 테스트를 실시하며 → 테스트하고 (문서 본문의 굳은 기술 용어는 둔다. 화면 문구의 도메인 한자어는 ui-copy.md §2)
- V14 범용 정책동사 수렴 [S2] 확대·강화·개선·확보·마련·구축 + 추상 목적어, 만능 "설계·구조" → 구체 행위로 (도시·설비 설계 같은 글자 그대로의 쓰임은 둔다)
- V15 출처 없는 권위 [S2] 전문가들은·많은 사람들이·\~로 알려져 있다·\~다는 분석이다 → 출처를 대거나 직접 서술. 출처를 지어내지 않는다
- V16 지시관형사 반복 [S2] 해당·본·당·동 → 이·그 또는 생략 | 해당 기능을 쓰면 해당 결과 → 이 기능을 쓰면 결과
- V17 같은 주어 반복 [S2] 나는/팀은/시스템은 연달아 → 첫 문장에만 (주어 전환·대비는 둔다)
- V18 광고성 영어 [S2] seamless·robust·leverage → 매끄러운·견고한·활용하다 (API·token·prompt 같은 표준 용어는 원어 유지. prompt → 지시문 같은 기계 직역 금지)
- V19 영어 병기 반복 [S2] 괄호 영어를 매번 → 첫 등장만
- V20 영어 관용구 직역 [S1] \~의 중심에·A에서 Z까지·\~의 세계 → 한국어 표현 | 산업의 중심에 있다 → 산업의 핵심이다
- V21 수렴 상투구 [S1] 여러 신호/지표가 한 방향을 가리킨다·한곳을 향한다 → 무엇이 무엇을 보여주는지 그대로 쓴다 | 지표들이 한 방향을 가리킨다 → 세 지표 모두 지난달보다 올랐다
- V22 빙빙 도는 지시 [S2] 여기에 맞춰져 있다·그쪽에 가깝다·그런 쪽이다 → 가리키는 대상을 명사로 적는다 | 설계는 그쪽에 가깝다 → 설계는 읽기 성능을 먼저 본다

## T. 번역투

- T1 "\~에 대해(서)" [S2] 목적격으로 바로 이을 수 있는 경우 → "X를 V" | 미래에 대해 분석 → 미래를 분석 (의견·생각의 대상은 둔다)
- T2 "\~를 통해" [S2] 한 단락 3회 이상일 때만 → \~로·\~해서·\~함으로써로 나눈다 (사람도 2-3배 더 쓴다. 1-2회는 둔다)
- T3 "\~에 있어(서)" [S1] → \~에서·\~할 때 | 교육에 있어서 → 교육에서
- T4 "\~와 관련하여/관련된" [S2] → \~에·\~의·목적격 | 보안과 관련하여 강화 → 보안을 강화
- T5 "\~에 기반하여/\~을 바탕으로" [S2·2회] → \~로·\~를 보고 (데이터 기반 같은 굳은 합성어는 둔다)
- T6 "가지고 있다", make/take/give + 명사 직역 [S1] → 형용사나 "\~이 있다" | 우수한 성능을 가지고 있다 → 성능이 우수하다 (물리적 소유는 둔다)
- T7 이중 피동 [S1, 비문] \~되어지다·\~지게 되다 → 단일 피동이나 능동 | 판단되어진다 → 판단된다
- T8 "\~에 의해" 피동 [S2] → 행위자를 주어로 | 연구팀에 의해 개발됐다 → 연구팀이 개발했다
- T9 자동 피동 [S2] 만들어지다·이루어지다 → 능동 | 합의가 이루어졌다 → 합의했다
- T10 "\~할 수 있다" 밀집 [S2] → 사실이면 단언, 일부만 바꿔 리듬을 깬다. 다중 헤지(\~할 수 있을 것이다)는 1회도 고친다 (진짜 가능성·능력·허가, 의학·법률·정책 글의 헤지는 둔다)
- T11 "\~을 위해" 밀집 [S2·2회] → \~려고·\~도록 | 매출 증대를 위해 → 매출을 늘리려고
- T12 "\~라는 점에서" 인과 [S2] → \~서·\~기 때문에 | 빠르다는 점에서 효율적 → 빨라서 효율적
- T13 추상 주어 + 만능·이동 동사 [S1] 가져오다·제공하다·보여주다·이끌다, 추상명사가 "나가다·묻는다" → 구체 주어나 부사절 | 트렌드는 기회를 가져온다 → 이런 흐름에서 새 기회가 열린다, 메일로 나갈 이탈 → 메일 발송 대상
- T14 문맥 없는 대명사 [S1] 그·그녀·그것·이는 → 직전 두 문장의 선행 후보가 0개면 명사구, 1개면 생략, 2개 이상이면 명사구. 애매하면 둔다
- T15 조사 빠진 명사 나열 [S2] AI 기술 발전 속도 가속화 → AI 기술의 발전 속도가 빨라지고 있다. 명사형을 "\~해야 한다" 로 일괄 풀지 않는다
- T16 긴 관형구 [S2] 명사 앞 3어절 이상 수식 → 문장을 나눈다
- T17 이중 조사 [S2] \~에서의·\~으로의·\~에의·\~으로부터의 → 절로 푼다 | 일터에서의 변화 → 일터가 어떻게 바뀌는지 (단순 "의" 는 대상 아님)
- T18 진행 피동 반복 [S2] \~되고 있다·\~지고 있다 → 일부를 단순 시제로
- T19 문두 "그리고" [S2] 영어 and 식 → 삭제하거나 \~고로 잇는다
- T20 "\~것이다" 종결 [S2] 사실 진술의 \~할 것이다, 결말의 \~다는 것이다·\~다는 뜻이다·\~인 셈이다 → 현재형이나 "\~다" (예측·약속은 둔다. 논설문은 사람도 많이 쓴다)
- T21 '-들' 기계적 부착 [S3] 수량사·수식어와 겹친 복수 → 뺀다 | 많은 사용자들이 → 많은 사용자가
- T22 "\~라고 알려진/일컬어지는" [S3] → 단순화 | 'AGI'라고 알려진 범용 인공지능 → 범용 인공지능(AGI)
- T23 호칭 직역 [S2] Mr./Dr. → 그/그녀 → 직함(박사님, 과장님)이나 생략
- T24 추상 개념 + 물리 서술어 [S2] 점수·범위·책임·가격 같은 추상 주어·목적어에 위치·동작·속성 서술어(아래에 있다, 나란하다, 찍히다, 얹다, 닿다, 넘다, 열리다, 가르다, 자리) → 개념어와 수치로 직접 | 점수가 경쟁 모델 바로 아래에 찍혔다 → 점수가 경쟁 모델보다 2점 낮다 (수치 비교의 "넘다"·"밑돌다" 처럼 굳은 표현은 둔다. T13 은 주어+이동 동사, 이것은 서술어·수식어 쪽이다)

## H. 서법·완곡

- H1 이중 완곡 [S1] \~할 가능성이 있을 수 있다·\~할 수 있을 것으로 보인다 → 완곡 표지 하나만 남긴다. 하나가 남으니 단정이 아니다 | 개선될 수 있을 것으로 보인다 → 개선될 것으로 보인다 (→ 개선된다 는 틀림)
- H2 같은 추측 종결 반복 [S2] \~로 보인다·\~로 판단된다 → 종결만 바꾸고(\~인 듯하다, 아직 단정하기 이르다) 확신도는 유지
- H3* 당위 결말 문단 연속 [S2·2문단] 문단 끝마다 \~해야 한다·\~할 필요가 있다 → 당위 문장을 문단 앞이나 중간으로 옮기기만 한다. 지우거나 서법을 바꾸지 않는다
- H4 "\~이 필요하다" 남발 [S2] → 주어·동사를 구체화하되 "\~해야 한다" 는 문단당 1회
- H5 안전 균형 표현 [S3] 양쪽 모두·장점도 있지만·균형 잡힌 → 다른 이유로 이미 고치는 문장에서만 한쪽 단언·구체 비교로
- H6 방어적 단서 문단 [S2] "그렇다고 \~로 돌리면 곤란하다", "물론 \~도 있겠지만" 처럼 반론을 미리 막는 문단 → 본문에서 빼고, 꼭 필요하면 각주나 끝의 참고 한 줄로 (그 단서가 결론을 실제로 제한하면 둔다)

## M. 명사화·수식

- M1 명사화 누적 [S2] -성·-적·-화, -기·-음 명사화가 쌓임 → 동사·형용사로 | 성공은 노력의 결과다 → 노력해서 성공했다
- M2* "\~적 N" 추상 체인 [S2] 전략적 함의·구조적 한계·본질적 변화 → 명사+명사나 풀어쓰기 | 구조적 한계 → 구조의 한계 (정착된 용어는 둔다)
- M3 "N 능력" 연쇄 [S2] 사고 능력은 뛰어나다 → 잘 사고한다
- M4 "의" 연쇄 [S2] 사용자의 만족도의 향상 → 사용자 만족도를 높이는 것
- M5 정도부사 중독 [S2] 매우·정말·대단히·극히 → 삭제하거나 수치로 (필자 육성의 구어는 둔다)
- M6 동의어 겹수식 [S2] 중요하고 핵심적인·역할과 기능·의미와 가치 → 하나만
- M7 잉여 술어 [S2] \~을 나타냅니다·\~하는 것이 가능하다·\~을 진행했다 → 술어를 줄인다 | 이 값의 의미를 나타냅니다 → 이 값의 의미입니다

## S. 구조·서식

- S1* 대칭 대구 [S1·2회] "A인가, B인가", "A가 아니라 B", "\~것이 아니라" → 가장 좋은 1회만 남기고 나머지는 비대칭 평서로. 쉼표만 지우지 말고 구조를 바꾼다. 전부 없애지 않는다 | 기술은 도구이고, 사람은 주체다 → 기술은 도구다. 사람이 그 도구를 쥔다
- S2 억지 3박자 [S3] 셋씩 묶은 나열·평행절 → 실제로 셋이면 둔다. 억지로 맞춘 것만 푼다 | 빠르고, 효율적이며, 안전합니다 → 빠르고 효율적입니다
- S3 기계적 병렬 [S2·4개] 첫째/둘째/셋째, 1) 2) 3) → 일부를 서술로, 또는 "우선·다음으로"
- S4 산문의 불릿 남용 [S2] 칼럼·리포트에서 짧은 불릿 연속 → 문단으로 (기술 문서·화면·체크리스트는 대상 아님)
- S5 도식 헤딩 [S2] 도입/본론/결론, "X: A에서 B로" 콜론 부제 → 산문이면 지우고 문서면 구체 명사구로 (학술·보고서의 실제 절 제목은 둔다)
- S6 안내 문장 [S2] 헤딩 바로 밑 "이 섹션에서는 \~를 다룬다" → 삭제
- S7 매 문단 요약문 시작 [S2] → 일부 문단은 사례·수치·장면으로 시작
- S8 이모지 [S1] 업무·기술 문서·칼럼 → 삭제 (SNS·제품 카피, 사용자 규칙이 허용하는 곳은 둔다)
- S9 볼드 남발 [S2] 문장마다 핵심어 볼드, "**머리말:**" 불릿 → 핵심 1-2곳
- S10 따옴표 강조 [S3] → 진짜 인용만 남긴다
- S11 괄호 부연 반복 [S2] "(이는 \~을 의미한다)" → 본문으로 넣거나 삭제
- S12 문두 접속사 [S2] 또한·따라서·즉·나아가·아울러·게다가 → 그 단락에서 절반쯤 덜어낸다. 문서 전체를 일괄로 지우지 않는다. "즉" 은 문서당 2회 이하
- S13 역접 남발 [S2] 문단마다 하지만·그러나 → 대비가 뻔하면 뺀다
- S14 메타 진입 [S3] "이는 \~을 의미한다", "이 관점에서 보면" 연속 → 3회 연속일 때만

## P. 문장부호

- P1* 연결어미 뒤 쉼표 [S1·여러 번] -고·-며·-지만·-면서·-어서·-는데 + 쉼표 → 지운다. **고친 글의 이 쉼표 수가 원문보다 늘면 실패다** | 좋아서, 산책을 → 좋아서 산책을 (주어가 바뀌는 긴 절 경계는 예외)
- P2 쉼표 과다 [S2] 쉼표 든 문장이 절반 이상, 주어 뒤 쉼표, 문장 끝 가까운 쉼표 → 마침표로 나누거나 지운다. 쉼표로 이은 절이 8어절을 넘으면 나눈다
- P3 줄표 [S2] 문장마다 — 부연 → 쉼표·괄호·문장 분리. 고치면서 새로 만들지 않는다. 사용자 원문에 있던 것은 둔다(사용자 규칙이 금지하면 예외)
- P4 도입 콜론 [S2] "다음과 같습니다:", "방법:" → 마침표나 문장 (시각·비율·키-값은 둔다)
- P5 가운뎃점 [S2] · 로 잇거나 나열 → 짝은 조사(와/과, 및), 나열은 쉼표나 `/`. 고유명사·인용 원문은 둔다

## R. 리듬

- R1* 장문 부재·길이 균일 [S2] 모든 문장이 비슷한 길이, 100자 넘는 문장이 없음 → 단락마다 짧은 문장 1-2개, 인접 문장을 이은 긴 문장 1개. 내용은 더하지 않는다 (기술 문서·화면 문구에는 적용하지 않는다)
- R2* 같은 종결 연속 [S2] 같은 어미 꼴(\~고 있습니다, \~ㄹ 수 있습니다, \~되었습니다)이 4문장 이상, 자동 "\~고 있다" → 꼴을 바꾼다(\~었다, \~ㄴ다, 명사형). 체가 같은 것(전부 -습니다)은 세지 않는다. 체와 시제는 그대로
- R3 단문 일변도 [S2] 복문이 거의 없음 → 인접 단문 2-3개를 연결어미·관형절로 묶는다
- R4 체 혼재 [S2] 한 단락 안 -습니다/-해요/-다 혼용 → 하나로 (grammar-style.md §4)

## 오탐 방지: 이것만으로는 AI 글이 아니다

반듯한 맞춤법과 일관된 문체, 격식체 한자어(법률·학술의 방증·기실), 접속사 한두 개, 줄표 하나,
단호한 짧은 문장, 개조식·번호 목록 그 자체, 편지투 인사. 무더기로 겹칠 때만 의미가 있다.

## 사람 글의 신호: 지킨다

곁말·자기 정정, 대구 한두 개, 원문에 있던 감탄·반문. 이것을 평균값으로 깎는 것이 가장 흔한 실패다.
