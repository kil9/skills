# 삽화 생성 레시피 (codex 위임)

[`../SKILL.md`](../SKILL.md) §2-2 에서 삽화를 넣기로 한 경우에만 편다. 삽화 없이 올리는 실행은
이 파일에 도달하지 않는다.

### 삽화 생성 레시피 (codex 위임)

```bash
codex exec --dangerously-bypass-hook-trust --dangerously-bypass-approvals-and-sandbox \
  --cd <스크래치 디렉터리> \
  "이미지 생성 도구(image generation)로 <주제> 에디토리얼 삽화 1장을 생성해줘.
   구도: <가로형(1536x1024) 등 + 장면 묘사>.
   스타일: 주제에 어울리게 자유롭게 고른다(플랫 벡터, 수채, 리소그래프, 애니메이션 풍 등).
   팔레트: 자유. 사이트가 극한 미니멀(무채색+블루)이므로 삽화까지 같은 톤이면 지루하다 —
     색·그라데이션을 써도 좋다. 단 다크모드 filter 와 어울리도록 라이트 톤 배경을 기본으로.
   간결함: 큰 형태 몇 개로 끝내고 색면 안은 매끈하고 깨끗하게 둔다.
   금지: 그레인·종이 질감·필름 노이즈·점묘·반점·먼지·떠다니는 입자, 잘게 쪼갠 붓 터치·모자이크·
     픽셀이나 비늘 같은 패턴·반복 무늬, 과한 디테일과 날카로운 미세 묘사.
   절대 금지: 이미지 안 글자·숫자·텍스트(생성 텍스트는 깨진다), 사람 얼굴 클로즈업.
   생성한 이미지를 <절대경로>.png 로 저장하고 최종 응답으로 경로와 픽셀 크기를 알려줘."
```

- 프롬프트에 **저장 절대경로**와 **이미지 내 텍스트 금지**를 반드시 명시한다. 생성물은 `~/.codex/generated_images/` 아래에 떨어지고 codex 가 지정 경로로 복사해 준다. 1회 1-5분 소요, 결과는 Read 로 눈검사한다(텍스트 유무·구도·톤).
- **자글자글한 미세 노이즈는 프롬프트로만 막는다**(위 `간결함`·`금지` 두 줄). GPT 이미지 생성은 색면 안에 잔 입자를 깔기 쉬운데, 질감·노이즈를 조금이라도 부르면 심해진다. 스타일은 주제에 맞게 자유지만 이 두 줄은 어떤 스타일에도 붙인다. 장면 묘사에도 hyper-detailed·intricate·8K 같은 디테일 유도어, 종이·필름 질감, 안개·먼지·입자를 넣지 않는다. 생성 뒤 노이즈 제거 필터(bilateral·mean-shift 등)는 그림이 뭉개져서 쓰지 않는다. 출처: blades 저장소 `blades-clean` 화풍(2026-10-23).
- 생성된 PNG 를 페이지에 넣는 방법(리사이즈·WebP 압축·base64 임베드·마크업)은 저장소 `AGENTS.md` §2-1 을 따른다.
