backlog 만 읽고 진척과 남은 일을 한 화면에 보여 준 뒤 다음에 할 것 하나를 추천한다. **읽기 전용**이다 —
상태가 틀려 보여도 고치지 말고 보고만 하며, 추천했다고 이어서 구현하지 않는다(그건 `/start-backlog`).
공통 전제는 [`../references/backlog-basics.md`](../references/backlog-basics.md).

## 읽기

`bash ~/.claude/skills/references/backlog-context.sh` 의 출력을 근거로 삼는다. `## hidden tasks` 에 실린
것은 목록이 감췄을 뿐 실재하는 일이니 빼지 않는다. exit 2 는 `/init-backlog`(옛 PLAN 이면
`/migrate-to-backlog`), exit 3 은 CLI 설치 안내.

## 보여 줄 것

- 마일스톤마다 진척(완료/전체)과 남은 태스크. 완료 마일스톤은 접는다. 마일스톤 없는 태스크는 따로 모은다.
- 태스크마다 **지금 착수 가능한지, 막혔으면 무엇에 막혔는지**(의존 대기 / Blocked 사유 = notes 첫 줄).
  진척 숫자만으로는 막힌 마일스톤과 그냥 안 한 마일스톤이 구별되지 않는다.
- `solo` label 은 표시해 둔다.
- 인자로 `m-N` 이 오면 그 마일스톤만 AC 요약까지 깊게, `--tasks` 면 마일스톤 없이 착수 가능한 것만 평평하게.

함정 둘: 태스크가 아직 없는 마일스톤(`0/0`)이 흔하니 0 으로 나누지 말 것. 한글 제목은 한 글자가 2셀이라
`%-32s` 식 정렬이 들쭉날쭉해진다 — 정렬하지 말고 공백 하나로 잇는 편이 안전하다.

## 추천

하나를 고르고 **왜 지금 그것인지** 한 줄을 붙인다. 이미 손댄 In Progress, 끝내기 가까운 마일스톤 순으로
보는 것이 보통이다. 전부 막혔으면 추천 대신 무엇을 풀어야 진행되는지를 태스크별로 보인다.
